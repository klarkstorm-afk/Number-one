# Number One — сайт и админка

Сайт хранится в GitHub и работает на GitHub Pages. Админка сохраняет изменения прямо в репозиторий, а сайт обновляется сам через 1–2 минуты.

## Файлы

- `index.html` — сайт
- `admin.html` — админка
- `style.css` — стиль
- `config.json` — ссылки, вакансии, музыка (меняется из админки)
- `reviews.json` — список отзывов (меняется из админки)
- `logo.webp`, `bg.webp` — логотип и фон
- папки `reviews/` и `music/` админка создаст сама при первой загрузке

## Установка (один раз)

1. На github.com создайте новый публичный репозиторий, например `number-one`.
2. Нажмите **Add file → Upload files** и перетащите все файлы и папки из архива. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через минуту сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/number-one/`.

## Токен для админки

1. Перейдите в **Settings профиля → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. В поле *Repository access* выберите **Only select repositories** и укажите ваш репозиторий.
3. В разделе *Permissions → Repository permissions* поставьте **Contents: Read and write**.
4. Создайте токен и скопируйте его (он показывается один раз).

## Как пользоваться

Откройте `https://ВАШ-ЛОГИН.github.io/number-one/admin.html`, введите токен и войдите. Логин и репозиторий подставятся сами.

- **Отзывы** — загружайте фото или скриншоты, меняйте порядок, удаляйте.
- **Ссылки** — Ассортимент, Опт, Менеджер, Наш чат.
- **Вакансии** — добавляйте, редактируйте, удаляйте.
- **Акции** — 5 блоков: Пн, Вт, Ср, Чт и Пт–Вс. На сайте автоматически показывается акция текущего дня.
- **Музыка** — 5 слотов: название и файл песни (до 40 МБ).

## Безопасность

- Токен хранится только в браузере, где вы вошли. Никому его не передавайте.
- На чужом устройстве после работы нажимайте **Выйти**.
- Если токен утёк, удалите его на GitHub и создайте новый.
